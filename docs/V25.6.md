# v25.6 — ปรับหน้า "รับคีย์" ให้เป็นเลย์เอาต์ "เวลาคงเหลือ" (สไตล์ที่ส่งภาพมา) + เพิ่มระบบต่ออายุ

## สรุปตามคำตอบ 3 ข้อ
1. กลไกยังเป็น **YouTube + Discord** เหมือนเดิม (ไม่ใช้ Work.ink/LootLabs — ไม่มี API token อยู่แล้ว)
2. ลงมือทำเลยด้วยระบบที่มีอยู่ ไม่ต้องรอ token อะไรเพิ่ม
3. ไม่ได้เลือกชัดว่าแทนที่หรือเสริม — ผมเลือกทำเป็น "ต่ออายุคีย์เดิม" (ไม่ใช่ออกคีย์ใหม่ซ้อน) ให้เข้ากับธีม "เวลาคงเหลือ" ที่สุด

## สิ่งที่เปลี่ยน
- **`components/MyKeyPanel.js`**: ออกแบบใหม่ทั้งหมดให้ตรงกับภาพอ้างอิง (Madium):
  - หัวข้อทักทาย "สวัสดี, {ชื่อผู้ใช้}"
  - การ์ดสถานะคีย์ด้านบน: ตัวเลขเวลาที่เหลือใหญ่ ๆ + แถบความคืบหน้า + วันที่หมดอายุ (แทนที่การ์ดคัดลอกคีย์เรียบ ๆ แบบเดิม)
  - ลิสต์ "รับ/ต่ออายุคีย์" เป็นแถวแบบการ์ด: ไอคอน + ชื่องาน + คำอธิบาย + ปุ่ม "เปิด"/"เข้าร่วม" (แทนลิสต์ข้อความธรรมดาแบบเดิม)
  - ปุ่มด้านล่างเปลี่ยนข้อความอัตโนมัติ: "รับคีย์" (ยังไม่มีคีย์) / "ต่ออายุคีย์" (มีคีย์อยู่แล้ว) / "ขอคีย์ใหม่" (คีย์เดิมหมดอายุไปนานแล้วแต่ยังไม่ถูกเพิกถอน)
- **`lib/keys.js`**: เพิ่มระบบ **ต่ออายุจริง** — กดทำครบ 2 ขั้นตอนซ้ำ (ตอนมีคีย์อยู่แล้วและยังไม่ถูกเพิกถอน) จะรีเซ็ตวันหมดอายุเป็น "อีก `DISCORD_KEY_DAYS` วันนับจากตอนนี้" เสมอ
  (ไม่บวกทบจากวันหมดอายุเดิม กันกดรัว ๆ แล้วได้เวลาสะสมไม่จำกัด) เดิมกดซ้ำแค่ "ได้คีย์เดิมคืน" เฉย ๆ ไม่ได้ต่ออายุอะไรเลย
