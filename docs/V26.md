# v26 — สตูดิโอ Obfuscate (พอร์ตจาก Python → JS เต็มระบบ)

## งานนี้ทำอะไร
แปลงตัว obfuscator ที่ให้มา (Python: parser + bytecode compiler + VM runtime generator, ~3,300 บรรทัด)
เป็น JavaScript ล้วน ให้รันในระบบเว็บได้โดยตรง (ไม่ต้องมี Python runtime) พร้อม UI หน้า "สตูดิโอ" แบบที่ส่งภาพมา

## ขอบเขตที่พอร์ต (เท่าที่ปุ่ม "Obfuscate" ของต้นฉบับใช้จริง)
ต้นฉบับ Python มี VM backend 3 แบบ (`vmgen.py`, `vmgen_cps.py`, `vmgen_mixed.py`) แต่ปุ่ม Obfuscate ของ CLI/เว็บ
เรียกเฉพาะ `vmgen_mixed.py` (closure-ต่อ-1-คำสั่ง + decoy state ปลอม + string pool เข้ารหัส) เท่านั้น จึงพอร์ตเฉพาะ
เส้นทางนี้แบบครบ: `luaparse.py`→`compile.py`→`buildflags.py`→`vmgen_mixed.py`+ส่วนที่ใช้ร่วมจาก `vmgen.py`/`vmgen_cps.py`/`protection.py`
→ ไฟล์ใหม่ทั้งหมดอยู่ที่ `lib/obf/*.js` (luaparse, compile, buildflags, vmgen, vmgen_cps, protection, vmgen_mixed, pipeline)

ไม่ได้พอร์ต `vmgen.py`/`vmgen_cps.py`/`serialize.py` ส่วนที่เป็น backend แยกอื่น (`obfuscate_source`, `obfuscate_source_cps`)
เพราะปุ่ม Obfuscate ของเว็บไม่เรียกใช้อยู่แล้ว — ถ้าต้องการให้ครบทุก backend บอกได้ จะทำเพิ่มให้

## ทดสอบแล้วอย่างละเอียด (สำคัญมากสำหรับงานขนาดนี้)
ติดตั้ง Luau runtime จริงจาก GitHub release (luau-lang/luau) มาทดสอบ ไม่ใช่แค่ "ดูว่าโค้ดรันไม่ error" เฉยๆ:
- **Parser**: เทียบ AST กับ Python ทุก token แบบ byte-ต่อ-byte ผ่านทุกไฟล์ตัวอย่างจริงในโปรเจกต์ (`tests/samples/*.luau`)
  รวมไฟล์ `input.luau` ขนาด 8.4MB — **ตรงกันทุกไฟล์** รวมถึงเคสขอบ (string interpolation, hex/binary literal, compound
  assignment, if-expression, goto/label, generic for, varargs, method call) **ตรงกันทุกเคส**
- **Compiler**: เทียบ bytecode กับ Python แบบ byte-ต่อ-byte (ใช้ opmap คงที่ทั้งสองฝั่ง) ทุกไฟล์ตัวอย่าง + ไฟล์ 8.4MB — **ตรงกันทุกไฟล์**
- **buildflags (fold FLE_OBFUSCATED)**: ทดสอบการพับเงื่อนไขที่ซ้อนลึก (while loop, elseif chain, table constructor,
  if-expression, nested function) และการปฏิเสธชื่อ FLE_OBFUSCATED ที่สงวนไว้ (local/assign/parameter) — **ตรงกับ Python ทุกเคส
  รวมข้อความ error**
- **แต่ละ opcode (38 opcode) → โค้ด Lua**: ทดสอบ 56 กรณีครอบคลุมทุก opcode กับค่า operand หลายแบบ — **ผลลัพธ์เป็นสตริงตรงกับ
  Python เป๊ะทุกตัวอักษร**
- **ฟังก์ชันแปลงเลขทศนิยมเป็นข้อความ (`%.17g`)**: fuzz-test 3,000 ค่าสุ่ม (รวมเลขเล็ก/ใหญ่มาก, 0, -0, inf) — **ตรงกับ Python ทุกค่า**
- **flatten_handler (decoy dispatch state)**: รันจริงผ่าน Luau 30 รอบ (สุ่มใหม่ทุกรอบ) ตรวจว่าโค้ดที่ห่อไว้ทำงานครั้งเดียวถูกต้องทุกรอบ
- **End-to-end**: obfuscate ไฟล์ตัวอย่างจริงทั้งหมดแล้ว **รันผ่าน Luau จริง** เทียบ stdout/exit code กับต้นฉบับที่ไม่ได้ obfuscate —
  ตรงกันทุกไฟล์ (ยกเว้นเลขบรรทัดใน error message ซึ่งเป็นธรรมชาติของผลลัพธ์บรรทัดเดียว ตรวจแล้วว่า Python เองก็เป็นแบบนี้เหมือนกัน)

## UI (`components/ObfuscateStudio.js`)
เมนูใหม่ "สตูดิโอ Obfuscate" ในแดชบอร์ด (กลุ่ม "สคริปต์") 2 คอลัมน์แบบภาพที่ส่งมา: ซ้ายวางโค้ด Lua ขวาโชว์ผลลัพธ์
พร้อมปุ่มคัดลอก/ดาวน์โหลด หัวข้อ Prettify/Minify ใส่ไว้ตามภาพแต่ **ปิดการใช้งานไว้ก่อน** (ของจริงยังไม่ได้ต่อระบบ — ไม่อยากให้เข้าใจผิดว่าใช้ได้)

ผลลัพธ์ขึ้นต้นด้วย `-- This script was generated using Flexozy 2.1.0 [https://flexozy.xyz/]` ตามที่ขอ

## API (`app/api/obfuscate/route.js`)
`POST /api/obfuscate` `{script}` → `{ok:true, output}` ต้องล็อกอินก่อน จำกัด 8 ครั้ง/นาทีต่อ IP กันสแปม
จำกัดอินพุตไม่เกิน 300,000 ตัวอักษร (กัน serverless function หน่วง/timeout กับโค้ดที่ยาวเกินจำเป็น)

## ข้อจำกัดที่ควรรู้
- ยังไม่ได้ทดสอบกับโค้ด Lua ของจริงจากลูกค้าในปริมาณมาก ๆ — แนะนำให้ลองโค้ดจริงหลากหลายแบบก่อนเปิดให้ใช้งานทั่วไป
- ไม่ได้พอร์ต type-generic (`<T>`) และ optional-type (`?`) ใน type annotation เพราะ**ต้นฉบับ Python เองก็ไม่รองรับ 2 อย่างนี้อยู่แล้ว**
  (ตรวจแล้วว่า error เหมือนกันทั้งสองฝั่ง ไม่ใช่บั๊กที่เกิดจากการพอร์ต)
- Prettify/Minify ที่เห็นในภาพอ้างอิงยังไม่มีในโค้ด Python ต้นฉบับที่ให้มาด้วย จึงไม่ได้ทำส่วนนี้ (ใส่ปุ่มไว้แต่ปิดไว้) ถ้าต้องการให้ทำเพิ่มบอกได้
