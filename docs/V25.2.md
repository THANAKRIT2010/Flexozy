# v25.2 — ออกคีย์อัตโนมัติตอนล็อกอิน Discord + หน้าล็อกอินใหม่ + แอดมินเห็นผู้เคลม
(ต่อจาก v25 ที่ปิดหน้า "ตรวจสอบความปลอดภัย" ที่ล็อกอินไม่ได้)

## สรุปจากคำตอบของคุณ
"คนรับคีย์" ที่อยากให้แอดมินดู = คนที่ล็อกอินด้วย Discord บนเว็บ (ระบบเข้าร่วมเซิร์ฟเวอร์ Discord ให้อัตโนมัติอยู่แล้วตอนล็อกอิน — โค้ดนี้มีอยู่ก่อนแล้วใน lib/auth.js)
สิ่งที่ยังไม่มีคือ "ได้คีย์" หลังล็อกอิน — ส่วนนี้คือของใหม่ทั้งหมดใน v25.2

## สิ่งที่เพิ่ม
1. **ออกคีย์อัตโนมัติตอนล็อกอิน** (`lib/keys.js: keyForDiscord`, เรียกจาก `lib/auth.js`)
   - ล็อกอินครั้งแรกด้วย Discord → ได้คีย์ใหม่ทันที (อายุ 30 วัน ปรับได้ด้วย `DISCORD_KEY_DAYS`, สิทธิ์ `['*']` เหมือน auto-key เดิม)
   - ล็อกอินครั้งต่อไป (บัญชี Discord เดิม) → ได้คีย์เดิมคืน ไม่ออกใหม่ซ้ำ นับจำนวนครั้งที่เคลม/ล็อกอินไว้
   - ถ้าแอดมินเพิกถอนคีย์นั้นไปแล้ว ระบบจะไม่ออกคีย์ใหม่ให้เองเงียบ ๆ (กันคนโดนแบนล็อกอินใหม่แล้วได้คีย์คืน) ต้องให้แอดมินจัดการ
   - ปิดได้ทั้งระบบด้วย `DISCORD_KEY=0`
2. **หน้า "คีย์ของคุณ"** ในแดชบอร์ด (ทุกคนที่ล็อกอินเห็นได้ ไม่ใช่แค่แอดมิน) — โชว์คีย์เต็ม ปุ่มคัดลอก จำนวนครั้งที่ใช้/เคลม สถานะผูกเครื่องแล้วหรือยัง วันหมดอายุ
   มีปุ่ม "เคลมคีย์" กรณีระบบออกให้ตอนล็อกอินไม่สำเร็จ (ยิงไปที่ `POST /api/me/key`)
3. **หน้าแอดมิน "Key ผู้ใช้"**: คีย์ที่มาจากการล็อกอิน Discord จะโชว์โปรไฟล์ Discord (รูป+ชื่อ), IP ตอนเคลมล่าสุด, จำนวนครั้งที่เคลม/ล็อกอินแล้วได้คีย์เดิมคืน, วันที่เคลมครั้งแรก — ควบคู่กับ HWID/Roblox profile/IP ที่มีอยู่แล้วจากตอนใช้งานจริงในเกม
4. **หน้าล็อกอินใหม่** ที่ `/login` — อธิบายว่าล็อกอินแล้วจะได้อะไร (เข้าร่วม Discord อัตโนมัติ, รับคีย์ฟรี, จัดการลิงก์) ก่อนกดปุ่มไปหน้า Discord OAuth จริงที่ `/login/discord`
   (เดิมกดปุ่มแล้วเด้งไป Discord ทันที ไม่มีหน้ากลางนี้)

## ทดสอบแล้ว
- `keyForDiscord()`: ล็อกอินครั้งแรกออกคีย์ใหม่, ครั้งที่ 2 ได้คีย์เดิมคืนและนับจำนวนครั้งถูกต้อง, IP ตอนเคลมอัปเดตเป็นค่าล่าสุด, คนละบัญชี Discord ได้คนละคีย์, คีย์ที่ถูกเพิกถอนแล้วไม่ถูกออกใหม่ให้เงียบ ๆ — ผ่านทุกกรณี
- `next build` ผ่านทั้งโปรเจกต์ รวมหน้า `/login` และ route `/api/me/key` ใหม่
- ยังไม่ได้ทดสอบ OAuth จริงกับ Discord (ต้องมี DISCORD_BOT_TOKEN/DISCORD_GUILD_ID/CLIENT_ID/CLIENT_SECRET ตั้งค่าไว้จริง)
