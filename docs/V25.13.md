# v25.13 — หน้ารับคีย์แบบ Earn time + เช็ก Discord อัตโนมัติด้วยบอท v2

## หน้าตา/การทำงาน
- `components/MyKeyPanel.js` + `app/fx.css` (ท้ายไฟล์): การ์ด "เวลาคงเหลือ" + การ์ด "รับเวลาเพิ่ม" มี 2 ภารกิจ (YouTube, Discord) แต่ละข้อมีปุ่มเริ่ม + ตัวบอกขั้น 1→2
- กด **เริ่ม** → เปิดลิงก์ในแท็บใหม่ → ผู้ใช้กลับมาหน้านี้ → นับ 10 วิ → หมุนตรวจสอบ → ผ่าน (ถ้าออกจากแท็บระหว่างนับ จะกลับไปรอใหม่)
- ปุ่มรับ/ต่ออายุคีย์เปิดใช้ได้เมื่อผ่านครบ 2 ภารกิจ — **ต่ออายุก็ต้องทำใหม่ทุกครั้ง** (ของเดิมกดต่ออายุแล้วเจอ "กรุณายืนยันว่าติดตาม YouTube แล้ว")

## ฝั่งเซิร์ฟเวอร์ (`app/api/me/key/route.js`)
- `POST {action:'start',task}` บันทึกเวลาเริ่มลงคุกกี้เซ็น `fxq` (30 นาที ผูกบัญชี)
- `POST {action:'verify',task}` ต้องผ่านอย่างน้อย ~9 วิตั้งแต่ start · discord = เช็กสดผ่านบอท v2 · youtube = ผ่านด้วยเวลา
- `POST {action:'claim'}` ต้องผ่าน youtube แล้ว และเช็ก Discord สดอีกรอบเสมอก่อนออก/ต่ออายุคีย์ ออกแล้วล้างคุกกี้
- GET ส่ง `days` (DISCORD_KEY_DAYS) ไปแสดงเป็น chip "+N วัน"

## บอท v2 (`lib/keys.js`)
- `discordMemberStatus()` → `member` / `not_member` / `error` (แยก "ไม่ได้เข้า" ออกจาก "เช็กไม่ได้")
- ใช้ `DISCORD_BOT_TOKEN_V2` (ไอดีบอท `DISCORD_BOT_V2_ID` ค่าเริ่มต้น 1543560070715936858) ถ้าไม่ตั้งใช้ `DISCORD_BOT_TOKEN` เดิม · ตั้ง token v2 แล้วระบบเทียบไอดีใน token กับไอดีบอท กัน token ผิดตัว
- `DISCORD_AUTO_JOIN=0` (`lib/auth.js`) ปิดการดึงเข้าเซิร์ฟเวอร์อัตโนมัติตอนล็อกอิน

## ข้อจำกัด
- YouTube: เว็บเช็กไม่ได้จริงว่ากดติดตามหรือยัง (ต้องให้ผู้ใช้ล็อกอิน Google/ใช้ YouTube API) จึงเป็นการ "กดเริ่ม + รอ 10 วิ"
