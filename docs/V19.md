## ลดการใช้ KV (เทียบกับ v18)
| จุด | ก่อน | หลัง |
|---|---|---|
| หน้า "ลิงก์ของฉัน" | อ่าน **ทุกลิงก์ทั้งระบบพร้อมซอร์ส** แล้วกรอง | อ่านดัชนีเมตาของเจ้าของ (`vo:<uid>`) ไม่มีซอร์ส + `HMGET views` 1 คำสั่ง (ข้อมูลเก่าเติมดัชนีให้เองครั้งแรก) |
| ตัวเลขสถิติหน้าแรก | `HGETALL vault` + `views` ทั้งหมด | `HLEN` + `HVALS views` + `SCARD` (ไม่ดึงซอร์ส) |
| นับยอดรัน | 1 `HINCRBY` ต่อการรัน | รวมเป็นชุดต่อ instance ผ่าน pipeline (ทราฟฟิกสูง ≈ 100 ครั้ง → ~12 คำสั่ง) |
| `/raw` `/stage` | `HGET vault` + `HGET views` ทุกคำขอ | แคชหน่วยความจำ 10 วินาที ไม่อ่าน views |
| ตรวจ IP ที่ถูกแบน | `EXISTS` ทุกคำขอ | แคช 30 วิ (เจอแบน) / 2 วิ (ไม่เจอ) |
| กระเป๋า TOKEN | `HSETNX`+`HGET` ทุกครั้ง | `HGET` ก่อน เขียนเฉพาะครั้งแรก |
| config หน้าเว็บ | แคช 5 วิ | แคช 30 วิ |
| หน้าแดชบอร์ด | หลายคำขอ | `/api/dash` คำขอเดียว แคช 15 วิต่อผู้ใช้ (`?fresh=1` หลังแก้ไข) |
> ข้อแลกเปลี่ยนที่ควรรู้: ยอดรันค้างในหน่วยความจำได้ไม่เกิน ~20 วินาที (instance ที่ถูกปิดกลางทางอาจเสียยอดท้ายชุด) และการแก้ซอร์ส/ลบลิงก์มีผลกับ `/raw` ใน instance อื่นช้าได้ถึง 10 วินาที

## ความปลอดภัยที่เพิ่ม
- เพดานลิงก์ต่อบัญชี (`MAX_LINKS_PER_USER`, ค่าเริ่มต้น 200) · ตอบ 429 `too_many_links`
- จำกัดการกดเข้าสู่ระบบ Discord ต่อ IP (20 ครั้ง / 5 นาที) ในหน่วยความจำ ไม่เสีย KV
- Header เพิ่ม: `Cross-Origin-Resource-Policy`, `X-Permitted-Cross-Domain-Policies`, CSP `upgrade-insecure-requests`, `Cache-Control: no-store` สำหรับ `/api` `/admin` `/login` `/logout`
- แอดมินปรับ TOKEN ถูกบันทึกใน log ความปลอดภัย (ดูที่ `/admin/settings`)
- โหมดเข้มงวด `EXEC_STRICT=1` (จาก v18) · ระบบกันบอต/token ครั้งเดียว/ผูก IP+UA เดิมยังทำงานครบ

## แบน / ปลดบล็อก IP จากหลังบ้าน (v19.1)
- ไปที่ `/admin/settings` → แผง "แบน / ปลดบล็อก IP": ใส่ IP + ระยะเวลา (1 ชม. / 24 ชม. / 7 วัน / 30 วัน / ถาวร) + เหตุผล แล้วกด "แบน IP" · กด "ปลดบล็อก" ที่แถวใดก็ได้เพื่อปลด
- รายการรวม IP ที่ **ระบบแบนอัตโนมัติ** (strike / ดึง stub รัว ๆ) ไว้ด้วย จึงปลดบล็อกคนที่โดนแบนผิดได้ · ปลดแล้วระบบล้างตัวนับ strike ให้ จะไม่โดนแบนซ้ำทันที
- มีผลกับ `/loader` `/raw` `/stage` `/auth` (คืน 403) — หน้าเว็บและหลังบ้านไม่ถูกบล็อก จึงแบนตัวเองออกจากแอดมินไม่ได้
- API: `GET/POST/DELETE /api/admin/bans` (แอดมินเท่านั้น) · ทุกการแบน/ปลดบันทึกใน log ความปลอดภัย
- ข้อจำกัด: instance อื่นอาจเห็นผลปลดบล็อกช้าได้ถึง ~30 วินาที (แคชในหน่วยความจำ) · แบนทั้งช่วง (เช่น `34.12.*`) ยังใช้ ENV `BLOCK_IPS`
