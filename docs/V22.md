# v22 — หน้าล็อกสำหรับคนเปิดลิงก์ตรงในเบราว์เซอร์ + ซีลสคริปต์แน่นขึ้น
- `lib/bots.js`: เพิ่ม `lockPage()` — ตอบกลับเป็นภาพ ASCII ล้วน ไม่มีคำใบ้เกี่ยวกับระบบ/โดเมน/โครงสร้างไฟล์ใด ๆ
- `lib/vault.js` → `denied(req)`: เปิดลิงก์ตรงในเบราว์เซอร์ (isBrowser) = lockPage() · บอท/เครื่องมือ/IP-UA ที่ถูกบล็อกอื่น ๆ (isBot ฯลฯ) ยังได้ข้อความสั้นแบบเดิม
- มีผลกับทุกจุดที่เรียก `denied(req)` อยู่แล้ว: /loader /bootstrap-source /bootstrap-info /game-script /raw /stage /auth /ping (ไม่ต้องแก้ทีละไฟล์)
- `lib/seal.js`: เปลี่ยนคีย์สตรีม XOR จาก "คีย์วนซ้ำ + เลขไล่บวก" (มีคาบ) เป็น xorshift32 ยาวเท่าข้อมูล (ไม่ซ้ำคาบในทางปฏิบัติสำหรับสคริปต์ทั่วไป) +
  แทรกบรรทัดหลอกแบบสุ่ม 2–5 บรรทัดทุกครั้งที่ซีล — รูปแบบตัวถอดรหัสไม่ซ้ำกันแม้แต่ 2 ครั้งติดกัน
- ทดสอบแล้ว: สุ่มสร้างตัวถอดรหัส 30 ครั้ง ผ่าน luaparse (ไวยากรณ์ถูกต้องทุกครั้ง) และถอดรหัสกลับได้ค่าตรงต้นฉบับทุกครั้ง (รวมข้อความไทย/อิโมจิ/สคริปต์ยาว)
- ยังไม่ได้ทดสอบบน Roblox executor จริง — ควรลองรันลิงก์จริงอย่างน้อย 1 ครั้งก่อนใช้งานจริงทั้งระบบ
