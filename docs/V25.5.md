# v25.5 — ล็อกอิน Discord ที่โดเมนหลัก แล้วเด้งไป app.flexozy.xyz

## ตามที่สั่งแก้ไข
"ให้มันล็อกอินหน้าปกติ แล้วค่อยเด้งไป app.flexozy.xyz คือล็อกอินดิสคอร์ดหลัก ให้มันเชื่อมกัน"
→ Discord OAuth (login + callback) ยังเกิดที่โดเมนหลักเหมือนเดิมตาม `DISCORD_REDIRECT_URI`/Discord Developer Portal ที่ตั้งไว้
(ไม่ต้องแก้อะไรตรงนั้น — แก้แค่ปลายทางหลังล็อกอินสำเร็จ)

## สิ่งที่เปลี่ยน (`lib/auth.js`)
เดิม: ล็อกอินสำเร็จแล้ว เด้งกลับไปหน้าแรกของ "โดเมนเดียวกับที่ล็อกอิน" เสมอ
ใหม่: ถ้าตั้ง `APP_URL` ไว้ ล็อกอินสำเร็จจะเด้งไปที่ `APP_URL` แทน (เช่น `https://app.flexozy.xyz/`)
ไม่ตั้งค่านี้ = พฤติกรรมเดิมทุกอย่าง

## ต้องตั้งค่า (ใน environment variables ของโปรเจกต์)
```
APP_URL=https://app.flexozy.xyz
COOKIE_DOMAIN=flexozy.xyz
```
**ทำไมต้องมีทั้งสองตัว**: Discord ล็อกอินเสร็จที่โดเมนหลัก (เช่น flexozy.xyz) เซสชันจะถูกตั้งไว้ที่โดเมนนั้น
ถ้าไม่ตั้ง `COOKIE_DOMAIN` ให้ครอบคลุมทุกโดเมนย่อย พอเด้งไป `app.flexozy.xyz` ระบบจะอ่านเซสชันไม่เจอ (เหมือนยังไม่ได้ล็อกอิน)
ต้องตั้งทั้งคู่คู่กันเสมอ — ตั้งแค่ `APP_URL` อย่างเดียวจะเด้งไปถูกที่แต่ "เหมือนไม่ได้ล็อกอิน" ที่ปลายทาง

## ลำดับการทำงานหลังตั้งค่าครบ
1. ผู้ใช้กดล็อกอิน (ไม่ว่าจะมาจาก flexozy.xyz หรือ app.flexozy.xyz ก็ได้ เพราะ `/login/discord` ใช้ `DISCORD_REDIRECT_URI` คงที่อยู่แล้ว)
2. ยิง OAuth ไป Discord → กลับมาที่โดเมนหลักตาม Redirect URI ที่ตั้งไว้ใน Discord Developer Portal
3. ตั้งเซสชัน (ใช้ร่วมกันได้ทุกโดเมนย่อยเพราะ COOKIE_DOMAIN) แล้วเด้งไป `APP_URL` → หน้าแดชบอร์ดที่ app.flexozy.xyz พร้อมล็อกอินอยู่แล้วทันที
