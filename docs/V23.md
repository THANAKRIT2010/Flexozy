# v23 — สคริปต์หลอกสำหรับบอทไล่เส้นทาง (deobfuscator/dump bot)
- ปัญหา: บอทที่จำลองการรันสคริปต์จริง (เช่นบอท Discord "Free-Deobfuscator") ไล่ loadstring จนได้โค้ดจริงออกมาเป็นข้อความอ่านได้
  — นี่คือข้อจำกัดที่หลีกเลี่ยงไม่ได้ 100% ถ้ามีคนจำลองการรันสคริปต์ได้สมบูรณ์แบบ สุดท้ายต้องเห็นโค้ดจริงเสมอ (Kerckhoffs' principle)
- สิ่งที่ทำได้จริง: ตรวจจับ "พฤติกรรมผิดปกติ" แล้วสลับเป็นสคริปต์หลอกแทนโค้ดจริง โดยไม่บอกอีกฝ่ายว่าโดนจับได้ (เนียนกว่าแบน/บล็อกตรง ๆ)
## วิธีทำงาน
- `lib/db.js` → `traceRisk(ip, code)`: นับจำนวน "โค้ดต่างกัน" ที่ IP เดียวแตะภายใน 10 นาที (ค่าเริ่มต้น) ผู้เล่นจริงมักวิ่งแค่ลิงก์/ฮับของตัวเอง 1-2 อัน
  ถ้าเกิน 3 โค้ดต่างกัน = เสี่ยงเป็นบอทที่ดึงโค้ดของคนอื่นหลายคนรัว ๆ (เช่นบริการ deobfuscator ที่รับงานจากหลายคนพร้อมกัน)
- `lib/decoy.js` → `decoyScript()`: สร้างสคริปต์ "ฮับ" หน้าตาใช้งานได้จริง (มีลิสต์ฟีเจอร์ "Auto Farm/ESP/Speed" ฯลฯ, แจ้งเตือน "โหลดสำเร็จ")
  แต่ทุกปุ่ม/ฟีเจอร์เป็นฟังก์ชันว่างเปล่า ไม่ทำอะไรจริง ไม่มีการ HttpGet ออกไปที่ไหนเลย สุ่มชื่อตัวแปร+รายการฟีเจอร์ใหม่ทุกครั้ง
- `app/stage/[code]/route.js`: เมื่อ `traceRisk` เป็นจริง จะส่ง `decoyScript()` แทน `v.script` จริง (เข้ารหัสด้วยกลไกเดิมทุกอย่าง โปรโตคอลเหมือนเดิมทุกจุด)
  ไม่นับเป็นยอดรันจริงให้เจ้าของลิงก์ (ไม่ incrViews) แต่ token/nonce ถูกใช้ไปตามปกติ และมีบันทึกเหตุการณ์ `trace_suspect` ไว้ในภาพรวมระบบ
## ตั้งค่า (ไม่บังคับ)
- `TRACE_GUARD=0` ปิดระบบนี้ทั้งหมด
- `TRACE_CODE_MAX` จำนวนโค้ดต่างกันสูงสุดก่อนเข้าเกณฑ์เสี่ยง (ค่าเริ่มต้น 3)
- `TRACE_WINDOW_SEC` ช่วงเวลาที่นับ (วินาที, ค่าเริ่มต้น 600 = 10 นาที)
## ทดสอบแล้ว
- `decoyScript()`: สุ่มสร้าง 25 ครั้ง ผ่าน luaparse ทุกครั้ง (ไวยากรณ์ถูกต้อง) และได้ผลลัพธ์ไม่ซ้ำกันทั้ง 25 ครั้ง
- `traceRisk()`: ทดสอบ logic จริง — โค้ดที่ 1-3 จาก IP เดียวไม่ติด, โค้ดที่ 4 ขึ้นไปติดเกณฑ์เสี่ยงทันที, IP อื่นไม่ถูกกระทบ
## ข้อควรระวัง (สำคัญ)
- เกณฑ์นี้วัดจาก "จำนวนโค้ดต่างกันต่อ IP" เท่านั้น — IP ที่ใช้ร่วมกันของคนจำนวนมาก (เช่น เน็ตโรงเรียน/ออฟฟิศ, VPN/proxy สาธารณะ) อาจโดนเหมาจับผิดได้
  ถ้าพบผู้เล่นจริงได้สคริปต์หลอกโดยไม่ได้ตั้งใจ ให้ปรับ `TRACE_CODE_MAX` ให้สูงขึ้น หรือปิดด้วย `TRACE_GUARD=0`
- ยังไม่ได้ทดสอบกับบอท deobfuscator ตัวจริง — ทดสอบเฉพาะ logic และไวยากรณ์ Lua เท่านั้น
