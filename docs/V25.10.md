# v25.10 — app.flexozy.xyz = หน้ารับคีย์โดยตรง ไม่ใช่แดชบอร์ด

## ย้ำสำคัญก่อน
log การ build ที่ส่งมาก่อนหน้านี้โชว์ route แปลกปลอม (`/keyapp`, `/api/keyflow`, `lib/earn.js` ที่ error) ซึ่งไม่ใช่โค้ดจากชุดที่ผมทำให้เลยสักไฟล์
การแก้ไขนี้ทำบนโปรเจกต์ **Flexozy-main ชุดที่ผมดูแลต่อเนื่องมาตลอด** (v25.9 เดิม) — ถ้า repo บน GitHub จริงมีไฟล์อื่นปนอยู่ การแก้นี้จะมีผลก็ต่อเมื่อนำไฟล์ชุดนี้ไป deploy ทับให้ตรงกันก่อน
ไม่งั้นต่อให้แก้ถูกแค่ไหน เว็บจริงก็จะยังไม่เปลี่ยนเหมือนที่ผ่านมาทุกรอบ

## สิ่งที่แก้ (`app/page.js`, `lib/auth.js`)
เดิม: โดเมนแอป (`APP_URL`) ยังไม่ล็อกอิน → เด้งไป `/login` / ล็อกอินแล้ว → เห็นแดชบอร์ดเต็มรูปแบบ (เมนูข้าง, ภาพรวม, ฯลฯ)
ใหม่: โดเมนแอปทั้งโดเมน (ทุก request ที่ `/`) = **หน้ารับคีย์แบบ Madium โดยตรง** เท่านั้น ไม่มีแดชบอร์ด ไม่มีแถบเมนูข้างอีกต่อไป
- ยังไม่ล็อกอิน → เด้งไปหน้า `/login` ของโดเมนหลักเหมือนเดิม
- ล็อกอินแล้ว → เห็นหน้า "สวัสดี, ชื่อผู้ใช้" + การ์ดเวลาคงเหลือ + ขั้นตอนรับคีย์ ทันทีที่ `/` เลย (ไม่ต้องผ่าน `/claim` หรือแดชบอร์ดอีก)
- ล็อกอินเสร็จ (Discord callback) ก็เด้งมาที่นี่ตรง ๆ เหมือนกัน

โดเมนหลัก (flexozy.xyz หรือกรณีไม่ได้ตั้ง `APP_URL` เลย) ยังเป็นแดชบอร์ด/หน้าแนะนำตัวตามเดิมทุกอย่าง ไม่กระทบ
