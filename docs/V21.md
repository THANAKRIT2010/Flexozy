# v21 — บันทึกผู้ส่งคำขอ + แบน IP / HWID / Roblox ID
- หลังบ้านในแดชบอร์ด: แอดมิน → "คำขอ & แบน" (`#bans`) · API: `GET /api/admin/seen`, `GET/POST/DELETE /api/admin/bans`
- แบนได้ 3 แบบ: IP (IPv6 แบนทั้ง /64) · HWID · Roblox UserId (ระยะเวลา 1 ชม. – ถาวร)
- บังคับใช้: IP ตรวจที่ /loader /bootstrap-* /game-script /raw /stage /auth /ping · HWID+Roblox ID ตรวจที่ /auth (Hub/key) และ /ping (ทุกลิงก์ที่มี tracker)
- แบนเครื่องแล้ว IP ใหม่ที่เครื่องนั้นใช้ จะถูกแบนตาม 24 ชม. อัตโนมัติ
- ลิงก์ทั่วไปที่ไม่ใช้ key เห็นแค่ IP ในคำขอแรก — HWID/Roblox ID ได้จาก /ping (tracker ส่ง HWID มาให้แล้ว)
- ข้อมูลบันทึก: KV hash `seen` / ไฟล์ `data/seen.json` (สูงสุด ~800 รายการล่าสุด) · รายการแบน: `bans`
