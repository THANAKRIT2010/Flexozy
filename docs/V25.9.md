# v25.9 — หน้ารับคีย์แยกเป็นหน้าของตัวเองจริง ๆ ไม่ใช่ view ในแดชบอร์ด

## ตามที่ย้ำว่าอย่าเข้าใจผิด
เดิม "คีย์ของคุณ" เป็นแค่ view หนึ่งที่สลับได้ด้วย URL hash ภายในแดชบอร์ด (ยังอยู่ใต้แถบเมนูข้าง/เลย์เอาต์เดียวกับหน้าเว็บหลัก) — v25.9 นี้แยกออกมาเป็นหน้าของตัวเองจริง ๆ ตามที่ต้องการ

## สิ่งที่เปลี่ยน
- **หน้าใหม่ `/claim`** (`app/claim/page.js`): หน้าแยกต่างหากโดยสิ้นเชิง ไม่มีแถบเมนูข้าง ไม่ใช่ view ในแดชบอร์ด — เช็กล็อกอินเอง (ยังไม่ล็อกอิน → เด้งไป `/login` ทันที)
- **เอา "คีย์ของคุณ" ออกจากแดชบอร์ด**: ลบออกจากแถบเมนูข้างและระบบ view ทั้งหมด — แทนที่ด้วยลิงก์ "รับคีย์ของคุณ" ในเมนูโปรไฟล์มุมขวาบน (กดชื่อผู้ใช้ → เห็นลิงก์นี้) สำหรับกลับไปดูทีหลังได้โดยไม่ต้องล็อกอินใหม่
- **ล็อกอินเสร็จแล้วเด้งไป `/claim` โดยตรง** (`lib/auth.js`) แทนที่จะเด้งเข้าแดชบอร์ดแล้วค่อยสลับ view

## ทดสอบแล้ว
- `next build` ผ่านทั้งโปรเจกต์ — เห็น route `/claim` แยกต่างหากในผลลัพธ์การ build ชัดเจน (ไม่ได้ปนอยู่ใน route เดียวกับแดชบอร์ด)
- ไวยากรณ์ของทุกไฟล์ที่แก้ผ่าน esbuild
- ยังไม่ได้ทดสอบ flow จริงบนเบราว์เซอร์ (ล็อกอิน → เด้งไป /claim → กดรับคีย์)
