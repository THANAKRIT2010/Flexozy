# v25.7 — app.flexozy.xyz ไม่โชว์หน้าโฆษณา/ฮีโร่อีกต่อไปถ้ายังไม่ได้ล็อกอิน

## ตามที่แจ้งว่าบัค
เปิด `app.flexozy.xyz` ตอนยังไม่ได้ล็อกอิน แล้วเจอหน้าแนะนำตัว (โลโก้ใหญ่ "FLEXOZY STORE" + สถิติ + การ์ดฟีเจอร์ + ปุ่ม "เข้าสู่ระบบด้วย Discord")
— หน้านี้มีไว้สำหรับโดเมนหลัก (ที่คนทั่วไปเข้ามาดูก่อนสมัคร) ไม่ควรโผล่ที่โดเมนแอปซึ่งมีไว้ให้คนที่ล็อกอินแล้วใช้งานแดชบอร์ดเท่านั้น

## สิ่งที่แก้ (`app/page.js`)
ถ้าตั้ง `APP_URL` ไว้ (เช่น `https://app.flexozy.xyz`) และคนที่เข้ามาที่โดเมนนั้นยังไม่ได้ล็อกอิน → **ไม่แสดงหน้าแนะนำตัวเลย**
ส่งไปหน้า `/login` ของโดเมนหลักทันที (เด้งฝั่งเซิร์ฟเวอร์ ไม่ใช่กะพริบแล้วค่อยเด้ง)

โดเมนหลัก (flexozy.xyz) ยังแสดงหน้าแนะนำตัวตามปกติทุกอย่างเหมือนเดิม ไม่กระทบ

## ต้องตั้งค่าเพิ่ม (ไม่บังคับ)
- `ROOT_URL=https://flexozy.xyz` — โดเมนหลักที่จะส่งไป ถ้าไม่ตั้งค่านี้ ระบบจะเดาเอาโดยตัดคำว่า `app.` ออกจาก `APP_URL` ให้อัตโนมัติ
  (เช่น APP_URL=https://app.flexozy.xyz → เดาเป็น https://flexozy.xyz) แนะนำให้ตั้งเองให้ชัดเจนถ้าโดเมนไม่ได้ใช้รูปแบบ app./ขึ้นต้น

## ทดสอบแล้ว
- ไวยากรณ์ผ่าน esbuild, `next build` ผ่านทั้งโปรเจกต์
- ยังไม่ได้ทดสอบจริงบนโดเมนจริง (ต้องตั้ง APP_URL ในระบบจริงก่อนถึงจะเห็นผล — ถ้ายังไม่ตั้ง พฤติกรรมเดิมไม่เปลี่ยนเลย)
