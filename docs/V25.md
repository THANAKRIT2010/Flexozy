# v25 — ปิดหน้า "กำลังทำการตรวจสอบความปลอดภัย" ที่ล็อกการเข้าเว็บ/ล็อกอินถาวร
## ปัญหา
หน้า "กำลังทำการตรวจสอบความปลอดภัย" (แบรนด์ "FLEXOZY Security" เลียนแบบ Cloudflare — เป็นของที่ระบบสร้างเอง ไม่ใช่ Cloudflare จริง
อยู่ที่ `lib/challenge.js`) ทำให้ "ทุกคนรวมถึงแอดมิน" เข้าเว็บไม่ได้เลย วนลูป "ยืนยันไม่สำเร็จ กำลังโหลดโจทย์ใหม่..." ไม่จบ
รวมถึงหน้า /login/discord ด้วย (เพราะเป็นด่านหน้าสุดของทุกหน้าเว็บใน middleware.js ก่อนถึงหน้าใด ๆ)

สาเหตุที่เป็นไปได้มากที่สุด: ตั้งค่า Cloudflare Turnstile (`TURNSTILE_SECRET_KEY`/`NEXT_PUBLIC_TURNSTILE_SITE_KEY`) ไว้แต่ site key
ไม่ตรงกับโดเมนจริง ทำให้ widget verify ไม่ผ่านตลอด และถ้าตั้ง `TURNSTILE_STRICT=1` ไว้ด้วย ระบบจะปฏิเสธทันทีโดยไม่สนใจ
proof-of-work สำรอง — กลายเป็นล็อกถาวร ไม่มีทางผ่านได้เลยจนกว่าจะแก้ค่า env

## ทางแก้ (v25)
`middleware.js`: เพิ่มสวิตช์ `CHALLENGE_GATE` — **ค่าเริ่มต้นคือปิด** (ไม่เรียก challengePage เลย) ทุกหน้าเว็บเข้าได้ตามปกติทันที
ถ้าต้องการเปิดกลับมาใช้อีกครั้ง (กันบอทสแปม/ยิงเว็บ) ตั้ง `CHALLENGE_GATE=1` — แต่แนะนำให้ตรวจสอบก่อนว่า:
- `TURNSTILE_SECRET_KEY` / `NEXT_PUBLIC_TURNSTILE_SITE_KEY` ตรงกับโดเมนจริงใน Cloudflare Turnstile dashboard (หรือลบสองค่านี้ออกเพื่อใช้แค่ proof-of-work ล้วน ๆ โดยไม่พึ่ง Cloudflare)
- ไม่ได้ตั้ง `TURNSTILE_STRICT=1` ไว้ (ถ้าไม่มั่นใจเรื่อง Turnstile ให้เอาออกหรือไม่ตั้งเลย)
- โค้ดส่วนอื่นของ `lib/challenge.js`, `lib/pass.js`, `app/api/challenge/verify/route.js` ยังอยู่ครบ ไม่ได้ลบทิ้ง แค่ปิดการเรียกใช้ชั่วคราว
