# v25.8 — ล็อกอินเสร็จแล้วเด้งตรงไปหน้า "คีย์ของคุณ" ไม่ใช่หน้าภาพรวม

## ตามที่แจ้ง
ล็อกอินแล้วเด้งมาหน้า "ภาพรวม" (สถิติ/กราฟ) ไม่ได้เข้าหน้ารับคีย์เลย

## สิ่งที่แก้ (`lib/auth.js`)
เดิม redirect ไปที่ `APP_URL/` เฉย ๆ (ลงเอยที่ view เริ่มต้น = ภาพรวม) → เปลี่ยนเป็น `APP_URL/#mykey`
ให้ตรงกับระบบ hash-routing ที่มีอยู่แล้วในแดชบอร์ด (เมนู "คีย์ของคุณ" ใช้ `#mykey` อยู่แล้ว) ล็อกอินเสร็จจะเด้งไปหน้านั้นทันที

## ทดสอบแล้ว
- ไวยากรณ์ผ่าน esbuild, `next build` ผ่านทั้งโปรเจกต์
- ยังไม่ได้ลอง flow จริงกับ Discord OAuth (ต้องล็อกอินจริงถึงจะเห็นผล)
