# รีสกิน v12 — ธีมสี · ตัวเลขสถิตินับขึ้น · หลังบ้านใหม่

## สิ่งที่เปลี่ยน
- **หน้าแรก** (`components/Home.js`, `app/page.js`): เมนูลอยแบบแคปซูล, Hero ไล่สีพร้อมออร่า, การ์ดสถิติที่ตัวเลข **ค่อย ๆ นับขึ้นจาก 0** เมื่อเลื่อนมาเห็น (`components/CountUp.js`)
- **ธีมสี**: ตั้งที่ `/admin/appearance` — มี 6 ธีมสำเร็จรูป + เลือกสีเอง ระบบสร้างสีอ่อน/สีคู่ให้อัตโนมัติ ใช้กับหน้าแรกและหลังบ้านพร้อมกัน (ใส่เป็นตัวแปร CSS ที่ `<html>` ใน `app/layout.js`)
- **ช่องแสดงสถิติ (แก้ไขได้)**: เพิ่ม/ลบ/สลับลำดับ/ซ่อนได้สูงสุด 8 ช่อง · ตั้งชื่อ หน่วย ไอคอน (14 แบบ) · ที่มาของตัวเลข = ยอดรัน / จำนวนลิงก์ / ผู้สร้าง / key ที่ใช้งานได้ / จำนวนแมพ / **กำหนดเอง** · มีช่อง "บวก/ลบเพิ่ม" · ปรับความเร็วการนับได้
- **หลังบ้านใหม่**: เมนูข้างแบบกระจก มีไอคอนและกลุ่มเมนู, มือถือใช้เมนูเลื่อนออก (drawer), การ์ดสถิติมีไอคอน + ตัวเลขนับขึ้น, ปุ่ม/ตาราง/ฟอร์มปรับตามธีม, หน้า "ภาพรวม" มีแผงสถิติที่โชว์บนหน้าแรก
- หน้าเดิม (ลิงก์/Key/แมพ/ความปลอดภัย) ยังทำงานเหมือนเดิม — เปลี่ยนเฉพาะหน้าตา

## ไฟล์ใหม่
`lib/site.js` · `lib/siteTheme.js` · `app/api/admin/site/route.js` · `app/admin/appearance/page.js` · `components/admin/AppearancePage.js` · `components/Home.js` · `components/CountUp.js` · `components/Icons.js`

## หมายเหตุการทำงาน
- ค่าตั้งเก็บใน Vercel KV (`site-config`) หรือ `data/site.json` ตอนรันในเครื่อง — บน Vercel ที่ไม่มี KV ข้อมูลอยู่ใน `/tmp` และอาจหายเมื่อ instance รีสตาร์ท (เหมือนระบบแมพเดิม)
- ตัวเลขจากระบบ (ยอดรัน/ลิงก์/key/แมพ) แคชไว้ 60 วินาที เพื่อไม่ให้การเปิดหน้าแรกทุกครั้งไปอ่านลิงก์ทั้งหมด; ส่วนที่ตั้งเองมีผลทันที
- ตัวเลขสถิติบนหน้าแรกเป็นข้อมูลรวมเท่านั้น (ไม่มีชื่อ/รหัส/ข้อมูลส่วนตัว) และ API แก้ไขเปิดให้เฉพาะแอดมิน (คนอื่นได้ 404)
- ถ้าอ่านค่าตั้งไม่ได้ หน้าแรกจะใช้ธีมเริ่มต้นและซ่อนช่องสถิติ ไม่ทำให้เว็บล่ม
